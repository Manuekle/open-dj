01Decks and mixer/

Two decks and a mixer, laid out like the hardware.

Load a track on each deck, beat match by ear or press Sync, and ride the EQ into the next one. Every control has a keyboard shortcut, and the master output records straight to a file.

  • Manual tempoType a BPM for a loose live take or a half-time read. It becomes a steady beat grid for sync and the planner.
  • RecordingMediaRecorder captures the master, sampler and drum machine included, and keeps it under Recordings.
  • SavingEvery change reaches IndexedDB within a second and a disk backup in ./data every few seconds.

8 hot cues and loops

Loop in, out or auto from 1/4 to 32 beats, beat jumps, and cues kept per track.

Beat sync, tempo ±25%

Sync on the estimated BPM, nudge with the jog wheel, and watch the waveform per deck.

Trim, 3-band EQ, color filter

Channel faders, level meters, master and crossfader. Decks trim toward -11 LUFS on load.

02Mixing analysisWeb Worker

Every track is read the moment you drop it in.

Tempo, beat grid, key, loudness and frequency bands are worked out in the browser, off the main thread. Nothing is uploaded to be analyzed.

  • TempoOnset strength, autocorrelation for the tempo, a comb filter for the phase of the first beat.
  • KeyA chromagram correlated with the Krumhansl-Kessler profiles, given as a key, a Camelot code and a clarity score.
  • LoudnessIntegrated LUFS per ITU-R BS.1770-4, with K-weighting and both gates.

    04Smart AutoMixAuto DJ

    An Auto DJ that explains every choice.

    While one track plays, AutoMix analyzes the next, loads it on the other deck, plans the transition and waits for the out point. Smart order sorts the queue by tempo, key on the Camelot wheel and energy flow.

    Each candidate gets a score from 0 to 100 and a separate confidence in the analysis behind it. A criterion with no data drops out of the score instead of being guessed.

    05AI second opinionOllama, local

    A second opinion from a model on your own machine.

    AI plan hands a local model, through Ollama, both tracks' analysis and the automatic plan. The answer is held to a JSON schema: phrase-aligned out and in bars, length, curve, EQ, effect and stem move, with a reason for each.

    The plan is kept like one you edited, tagged AI. Nothing is sent outside your machine.

      09Pageslocalhost:3000
      
    
      
      
      
        
      One app, six rooms.
      
        
      Projects hold their own tracks and the whole session: what each deck holds, EQ, effects, stem mutes, the queue, saved plans and hot cues. Switching projects saves the one you leave.
      
      
      
      
      
        
      /The DJ workstation: library, two decks, mixer, transition editor, AutoMix, set timeline, sampler and drum machine.
      
        
      /stemsEvery stem of a track on its own lane, loops and timed mutes, and a two-track stem mix with Auto blend and AI blend.
      
        
      /lyricsKaraoke with the timing of every word, an instrumental mode when the track has stems, and LRC export.
      
        
      /studioFour-track studio: record your voice over stems of your library, autotune it, export the mix as WAV.
      
        
      /playThe rhythm game, in four difficulties, with adjustable scroll speed and timing offset.
      
        
      /diagnosticsAn audio self-test for automation, pitch, clock and drift, to compare browsers side by side.

      11InstallMIT license
      
    
      
      
      
        
      One command, then open localhost.
      
        
      You need Docker Desktop with at least 8 GB of memory and about 10 GB of free disk. The first run takes 10 to 15 minutes, mostly downloads. Later starts take seconds.
      
      
      
      
      
        
        
          
      1. Install Docker
        Docker Desktop, or Docker Engine with Compose. Give it 8 GB of memory.
        2. 
          
      2. Clone and start
        This builds the app image with Node, ffmpeg, Demucs and its model, starts Ollama and pulls the AI model.
        
            
        $ git clone https://github.com/Manuekle/open-dj.git
$ cd open-dj && docker compose up -d --build
        3. 
          
      3. Open the app
        Go to http://localhost:3000. The AI plan button turns on once the model download finishes.
        4. 
        
      
        
      
          
      
            
            
            
          
      
          
      
            
      $ docker compose up -d --build
      
            
      Start, or update after a git pull.
      
            
      $ docker compose logs -f model
      
            
      Follow the model download.
      
            
      $ docker compose down
      
            
      Stop everything. Projects stay in ./data and the model stays in its volume.
      
          
      
          
      
            
      $ npm install
$ npm run setup:stems
$ ollama pull qwen2.5:7b
$ npm run dev
      
            
      For development, with Node.js 22, ffmpeg, uv and Ollama. Stems, lyrics and AI are optional: without them their buttons stay off.
      
            
      $ npm run setup:whisper
      
            
      Installs whisper.cpp and the large-v3 model for word-timed lyrics.
